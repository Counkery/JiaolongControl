## 3. 发现（按可利用性排序）

### R-01【高】生产构建保留 Vite 开发服务器回退，且 host object 无条件暴露

**证据链（静态可证）**：

1. `MainWindow.xaml.cs:456-458` —— 页面地址二选一：
   ```csharp
   view.Source = Directory.Exists(_webRoot)
       ? new Uri("https://app.local/index.html")
       : new Uri("http://localhost:5173");     // ← 无 #if DEBUG
   ```
2. `MainWindow.xaml.cs:550` —— host object 在**目录检查之前**无条件注册：
   ```csharp
   core.AddHostObjectToScript("bridge", Bridge.Instance);
   if (Directory.Exists(_webRoot)) { core.SetVirtualHostNameToFolderMapping("app.local", …); }
   ```
3. 产物字符串里确实存在 `http://localhost:5173` 与 `https://app.local/index.html`，确认回退分支被编译进发布版。
4. WebView2 的 `AreHostObjectsAllowed` 默认 `true`；一旦页面加载，`chrome.webview.hostObjects.bridge.*` 即可调用。

**为什么严重**：本程序按清单要求**以管理员身份运行**，而 `Bridge` 下挂 17 个控制器、152 个公开方法，其中包含 `Blding64.InitializeBldring`（装载内核驱动）与 EC 写入。即：

> 本机任意低权限进程监听 `127.0.0.1:5173` → 让应用加载其页面 → 该页面获得**管理员级**硬件与驱动控制权。

触发条件只要求应用目录里的 `WebRoot` 不存在。便携包通常解压在**用户可写目录**（下载/桌面），删除或改名 `WebRoot` 不需要管理员权限。这不只是"调试残留"，而是一条**本地提权链**。

**建议（三处，缺一不可）**：
- 回退分支加 `#if DEBUG`（或 `if (Debugger.IsAttached)`），发布版找不到 `WebRoot` 应直接报错退出，而不是连 localhost。
- 把 `AddHostObjectToScript` 移到 `if (Directory.Exists(_webRoot))` **之内**，仅在虚拟主机映射成功后才暴露 bridge。
- 增加 `NavigationStarting` 白名单：只允许 `https://app.local/`，其余 `e.Cancel = true`；同时处理 `NewWindowRequested`。

### R-02【高】WebView2 没有任何安全基线设置，前端无 CSP

**证据**：全仓库检索 `AreDevToolsEnabled`、`AreDefaultContextMenusEnabled`、`IsWebMessageEnabled`、`NavigationStarting`、`NewWindowRequested`、`AreHostObjectsAllowed` —— **命中 0 处**，全部走 WebView2 默认值。`WebRoot/index.html` 中也无 `Content-Security-Policy`。

**后果**：
- 生产环境可用 F12 / Ctrl+Shift+I 打开 DevTools，在控制台直接调用 `hostObjects.bridge` —— 拿到与 R-01 同等的控制面（需本机操作，但绕过 UI 限制）。
- 右键菜单、页面 `window.open` 未被约束；缺 CSP 意味着任何一次字符串注入（设备名、驱动版本、OSD 媒体标题等回显）都可能升级为脚本执行并触达 bridge。

**建议**：显式设置 `AreDevToolsEnabled = false`、`AreDefaultContextMenusEnabled = false`、`IsWebMessageEnabled` 按需、处理 `NewWindowRequested`；`index.html` 加 CSP（`default-src 'self'; script-src 'self' 'sha256-…'; object-src 'none'`，内联主题脚本用 hash 放行）。

### R-03【中】内核驱动的加载面依赖"应用目录不可写"这一隐含假设

`advapi32!CreateService` + `ChangeServiceConfig` + `StartService` 说明驱动是按**应用目录下的 `Drivers\Blding\JiaoLongDriver64.sys`** 注册为服务的。该 `.sys` 由 Bitland 签名（有效），但：

- 主程序 `exe/dll` **未签名**，用户无法校验发布物来源（zip 也无签名，仅能靠哈希）。
- 便携包多放在用户可写目录 → 能替换 `.sys` 的人也能替换 `.exe`。虽然未签名驱动在 64 位/HVCI 下加载会被拒，但**换成一个别的已签名驱动**（BYOVD 手法）是可行的。

**建议**：给 zip 与主程序签名（可用自签名 + 公布指纹，至少写明 SHA-256）；启动时用 `WinVerifyTrust` 校验 `JiaoLongDriver64.sys` 的签名主体是否为 Bitland；安装说明里强调"放在非共享、仅本人可写的目录"。

### R-04【中】包体有约 9.8 MB 无效负载

| 组成 | 大小 | 是否必需（x64 Windows） |
| --- | --- | --- |
| `runtimes/linux*`、`osx*`、`maccatalyst*`、`android*`、`browser`、`unix` | ≈ 5.3 MB | ❌ 不需要 |
| `runtimes/win-x86` | 3.1 MB | ❌ 不需要 |
| `runtimes/win-arm64` | 1.4 MB | ❌ 不需要 |
| `runtimes/win-x64`、`win` | 4.6 MB | ✅ 需要 |
| `WebRoot/assets/BackgroundVideo-*.mp4` | 2.2 MB | 可压缩/按需加载（占前端产物 60%） |
| `Microsoft.Web.WebView2.*.xml` | ≈ 800 KB | ❌ IntelliSense 文档 |
| `JiaoLongControl.pdb` | 118 KB | ❌ 发布版可去掉 |

**建议**：`Publish` 时用 `RuntimeIdentifier=win-x64` + 在 csproj 里剔除 `runtimes/**` 的非目标 RID，或直接 self-contained 单 RID 发布；`<DebugType>none</DebugType>` 或 `<DebugSymbols>false</DebugSymbols>` 于 Release；`<AllowedReferenceRelatedFileExtensions>` 排除 XML。

### R-05【低】`.dll.config` 仍声明 .NET Framework 4.8

`JiaoLongControl.dll.config` 里 `<supportedRuntime version="v4.0" sku=".NETFramework,Version=v4.8" />`，而实际是 .NET 8。该节点在新运行时下被忽略，属历史遗留；RE 角度它会误导排查者，建议删除。

### R-06【低】PDB 随包，但未泄漏本机路径

`JiaoLongControl.pdb`（118 KB）随包发布。字符串取证：**未发现**开发机路径（`C:\Users\…`、`WorkBuddy`、`worktrees` 命中 0）；唯一路径是 `D:\a\JiaolongControl\…`，属 GitHub Actions 的 SourceLink 映射。因仓库公开，泄露风险很低，但保留 PDB 会让人可以逐方法对照反编译结果，且对用户无价值。

### R-07【信息】SMU 运行时依赖不随包

`PawnIOLib.dll` **不在包内**（`pawnio_open` 为 DllImport）。`PawnIO` 构造函数刻意惰性初始化并有注释说明，缺失时不会拖垮启动，但 SMU 页在未安装 PawnIO 的机器上不可用。README 已写此前提，属设计选择；建议首次打开 SMU 页时给出明确的"未检测到 PawnIO"引导，而不是等到调用失败。

### R-08【信息】厂家 OSD 通过挂起进程抑制

`ntdll!NtSuspendProcess` 证据与源码一致：为压制 System 完整性的 `BLDFnHotkeyUtility` 而挂起其进程。属于"未文档化 API + 跨进程操作"的高特征行为；本机原厂软件已卸载时无实际动作（本轮已加启动自愈与降频，见 `PROJECT_AUDIT_2026-10-28.md`）。
